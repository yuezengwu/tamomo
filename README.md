# TAMOMO

> **状态：公开构想 / RFC，尚无可运行的训练实现。**

> **T**rain **A**I **M**odels **O**n **M**ac computers **O**nly

未来可以扩展为：

> **Train AI Models On Machines, Openly**

TAMOMO 是一项开放实验，研究普通 Mac 电脑能否通过真实网络协作，从随机初始化开始训练 AI 模型。

**让个人设备成为开放智能的共同生产者。**

## 愿景

今天的大模型训练依赖昂贵、集中且高速互联的算力集群。

TAMOMO 希望探索另一种可能：把许多小型、分散、性能不同且随时可能离线的计算设备，组织成可以共同完成训练任务的系统。参与者不需要拥有数据中心，也能观察、复现并改进一次真实的模型训练。

长期来看，我们希望个人和小团队能够共同发起训练，理解模型如何产生，并在已有成果上继续创造。开放的训练方法、可复现的过程和能够延续的协作关系，都应成为参与者可以使用的成果。

如果这条路线能够扩展到具有通用能力的模型，改变的将包括谁有能力创造 AI、谁能决定它学习什么，以及谁能继续改进它。实现这些价值，需要同时解决训练效率、数据来源、成果使用和协作决策问题。

即使这一远景尚未实现，可复现的小模型训练、低通信算法和可靠的设备协作工具，也应先为研究者、开发者和学习者提供价值。

## 个人设备能训练 AGI 吗

这是一个值得验证、尚不能承诺的长期问题。

- **单台个人设备**：可以研究小模型训练；本项目没有证据支持普通单机能在可接受的时间和成本内从零训练 AGI。
- **许多个人设备协作**：低通信训练和跨地域预训练已有先例，但家庭网络、设备内存、掉线和总成本仍需逐项验证。
- **最终达到 AGI**：还取决于算法、数据、训练方法和能力评估。设备更多、参数更大或训练 loss 下降，都不能单独证明通用智能已经实现。

TAMOMO 从可复现的小实验开始，逐步回答个人设备能够承担多大规模、什么类型的训练。

## 为什么值得投入

**对投资人**：值得检验的长期假设，是将分散、可中断的设备组织成有用的训练资源，并积累可复用的软件、成本测量和交付能力。未来可能出现训练工具、实验服务或协作基础设施的商业需求；技术优势、付费需求和可持续收入都需要分别证明。

**对贡献者**：参与可以留下可复现的实验、代码、模型和被记录的研究贡献，让后来者能够学习、检验和继续改进。项目应让参与者了解设备承担的任务与成本，自主选择参与和退出，并按明确的许可使用成果。

经济性首先按已有闲置设备评估：只计算训练额外造成的运行折旧与电费，历史购置支出及原本就会发生的时间折旧不重复计入。核心假设是把已有设备的闲置能力转化为有用的训练成果，再以相同质量下的实际成本检验其价值。

长期来看，TAMOMO 希望利用个人设备的自然升级降低等算力运行成本，通过软件减少协作损失，让更多训练任务进入成本优势区间。成本交点随设备、网络和价格变化，应持续用实测更新。

双方共同支持的近期目标，是让两台 Mac 完成一次可复现、可比较的从零训练。当前适合贡献相关工作、反例、实验设计和单机基线实现；项目尚未提供可接入的训练网络。

愿景、硬件观察、成本口径、相交曲线与后续实验见[本轮讨论总结](./docs/discussion-summary-2026-09-03.md)。已有证据、数量级估算和阶段性验证路线见[长期价值与可行性](./docs/long-term-value.md)。

## 为什么从 Mac 开始

- Apple Silicon 提供相对统一的硬件和软件环境。
- 统一内存允许小型设备尝试不同的模型和状态分配方式。
- MLX 已经提供训练、分布式通信和多机启动能力。
- MacBook、Mac mini 和 Mac Studio 电脑广泛存在于个人和小团队环境中。
- 从单一设备生态开始，先集中验证训练问题，再逐步解决其他平台的兼容问题。

这些理由用于说明实验平台的选择，性能和成本优势仍需实验验证。

## 相关工作与差异

TAMOMO 建立在已有研究和工程进展之上：

- [Apple MLX Distributed](https://github.com/ml-explore/mlx/blob/main/docs/src/usage/distributed.rst) 已提供多机启动、集合通信、数据并行和模型并行能力。
- [DiLoCo](https://arxiv.org/abs/2311.08105) 与 [OpenDiLoCo](https://arxiv.org/abs/2407.07852) 探索了跨低带宽网络的低通信语言模型训练。
- [INTELLECT-1](https://www.primeintellect.ai/blog/intellect-1-release) 完成了跨国家专业 GPU 节点的 10B 参数模型预训练。
- [IOTA / Train at Home 官方指南](https://docs.macrocosmos.ai/product-and-services/tah/tah-user-guide) 描述了 Mac 电脑参与训练网络的路径；这是项目方的产品说明，不能据此推断全部训练由个人设备完成。

TAMOMO 当前选择一个更窄的交集进行验证：

- 第一阶段只使用 Mac 电脑提供训练算力；
- 从随机初始化开始训练，并保留单机基线；
- 从可信节点出发，逐步加入真实网络、性能差异和节点退出；
- 公开复现实验所需的代码、配置、原始指标和 checkpoint；
- 在相同模型质量下比较时间、电量、流量和重算成本；
- 初始系统不依赖支付、代币、奖励或算力市场。

## 项目规则

- 用最小、可复现的实验回答当前问题，并保留可比较的基线。
- 用真实测量支持结论，区分事实、推断和未来设想。
- 保存有效结果、失败和限制，让新证据持续修正技术路线。
- 只在真实工作暴露出反复出现的问题时补充规则，不预先建设完整制度。

## 当前范围

当前关注：

- Apple Silicon 和 MLX；
- 从随机初始化开始的小模型训练；
- 单机、局域网多机和低通信训练方法；
- 异构性能、节点中断、恢复和训练正确性；
- 时间、能耗、流量和模型质量的统一测量。

当前不做：

- 支付、代币、奖励和算力市场；
- 商业化产品和市场扩张；
- 不可信公共节点和完整拜占庭容错；
- 在没有实验依据时训练更大的模型；
- 用一次演示替代可重复的工程证据。

## 当前进展

项目目前是一份公开 RFC，已有研究文档和可复算的成本曲线，尚无可运行的训练实现。第一步是建立单机 MLX 基线，再用两台 Mac 电脑复现同一训练任务。

先公开问题、愿景和验证方法，以便获得相关工作、反例和实验设计反馈。后续 RFC、正式实验记录和结论将通过带日期的 Git 提交保留，形成可追溯的公开记录。

## 语言

项目主要使用中文，包括研究、设计、实验记录和协作讨论。

代码标识、API、CLI 参数、协议字段和通用技术术语可以保留英文。关键公开文档在内容稳定后提供英文版本；中英文内容不一致时，以最新中文原文为准。

## 安全与权限

- 不在参与设备上执行协调器任意下发的代码。
- 不提交凭据、令牌、个人信息或私有网络信息。
- 使用许可明确并有记录的数据集和模型组件。
- 未经明确同意，不增加遥测或上传本地设备信息。
